# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Open an issue to report a bug or discuss a proposed change.
2. Fork the repository and create a branch for your changes.
3. Make your changes and verify the calculator still works by opening `index.html` in a browser.
4. Submit a pull request describing what you changed and why.

Please keep contributions focused and include clear steps to reproduce when reporting bugs.
